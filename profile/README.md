## 👋 关于我们

一个围绕《Among Us》模组的小社群。主要维护 **TheOtherUs-Edited（TOUE）** 模组，顺便搭了游戏记录查询网站、写了一些教程，偶尔传点视频。

## 当前主要维护的模组

### TheOtherUs-Edited (TOUE)

基于 TheOtherUs 的汉化与二次修改，加入了 100 多个职业，做了一些本地化调整。

- 📦 **GitHub 仓库**：[TheOtherUs-Edited](https://github.com/mxyx-club/TheOtherUs-Edited)
- 📖 **职业百科**：[theotherus](https://www.mxyx.club/archives/theotherus) 
- 🕹️ **支持的版本**：v2023.11.28 ~ v2024.6.4
- 📜 **开源协议**：GPL-3.0

> 顺便一提，TOUE 的重构版本在慢慢推进中，什么时候能出来还不确定，随缘开发。


### ✨ 特色

- 🧑‍🤝‍🧑 船员、伪装者、独立三大阵营，超 100 种职业
- 🎲 赌怪模式、轮抽选角、匿名模式等玩法
- 📈 游戏记录可查询 [toue.mxyx.club](https://toue.mxyx.club)
- 🔧 持续修 Bug，还在不断更新新职业、新功能。
